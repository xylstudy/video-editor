# 系统技法演示视频

2026-10-20 排查发现：原教学演示组件和渲染脚本仍在，但存储目录缺少全部 52 个内置技法演示文件；已有的 30 个视频属于个人知识来源片段。

已使用原有 `viral-structure-engine/remotion/src/TechniqueDemo.tsx` 补齐 `k_0` 至 `k_51`，包含转场、特效、剪辑技法与包装风格。生成文件存放在 `web/backend/storage/knowledge_demos/`，个人视频保持原样。系统列表另有一条历史“跨镜头特效契约”规则，没有独立教学演示。

## 页面入口

知识库 → 系统技法 → 卡片上的“播放演示”。点击后直接打开详情播放器；普通查看详情仍按需加载视频。列表显示演示数量，播放失败时可以重试。

## 补齐命令

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -u viral-structure-engine/render_knowledge_demos.py --built-in
```

该命令只选择 `k_数字` 内置条目，跳过已有非空文件。共享一次 Remotion 打包与浏览器进程，逐个渲染；临时文件成功后才替换为正式视频，结束后清理临时打包目录。生成视频依赖本机可运行 Remotion 的浏览器及 Node 环境。
