# 贴纸与独立特效知识

贴纸属于 `effect_type`。包装风格用于描述整片的组合策略，不能代替单个贴纸、描边、残影等技法的独立入库。

2026-10-22 已补齐 12 条独立特效，其中 5 类贴纸为卡通五官、头顶手绘反应、文字弹入、指示箭头、主体撕纸描边。另有主体增殖/残影、九宫格、播放器、故障、剪影及搜索引导卡。

## 自动提炼

`knowledge/effects.py` 合并 `effect_tracks` 与各镜头的 `effect_events`，优先保留镜头中的位置、运动路径、遮罩和参数。每种技法按 `effect_key` 单独入库，同一技法的多次出现保存为多条证据；全局轨道和镜头记录不重复计数。普通镜头运动和转场不误归为贴纸。只有文字提及、没有可定位观察的效果不伪造时间轴。

`knowledge_sync.extract_gene_knowledge` 由原来的“已有知识就跳过”改为增量补齐。已有结构、Hook、节奏、情绪、包装和人工知识保持原样；独立特效的证据改变时更新原条目，不另建重复记录。任务完成后的资产队列会自动完成这些步骤，不需要再手工整理知识。

## 真实示例

“效果示例”必须使用独立实拍素材重新制作；“原片示例”才截取来源视频。两者不再使用同一段原片。

贴纸以 SVG 重绘，锚点跟随独立素材中的光流轨迹；文字使用弹入动画，箭头、九宫格、播放器与故障层由代码实际叠加。主体描边、残影和增殖先用颜色种子与 GrabCut 取得透明主体，再以定格主体合成演示，并明确标注“定格主体抠像合成”。这不代表已经完成原片中动态主体的逐帧抠像迁移。

只从参考片取得片段、没有独立素材或缺少重建实现时，不再提供冒充效果示例的视频：保留原片入口，并显示待补齐原因。自动资产任务记录 pending_examples，示例阶段标记部分待补齐，不因已知的能力缺口反复重试。
入口：**知识库 → 我的知识 → 特效 / 贴纸**。可搜索“贴纸”“箭头”“撕纸”等关键词。详情显示应用对象、起止时间和折叠的位置/路径信息，保留效果示例与原片入口。

## 验证

任务 #12 的资产队列实际补齐 8 条独立效果，知识和示例从 5 增至 13；基因 #3 另补齐 4 条。重复提炼没有新增重复条目，原有 114 个媒体文件保持不变。记录见 `data/sticker-knowledge-backfill.json`，实拍示例截图见 `data/sticker-knowledge-examples.jpg`。自动提炼、补齐、证据更新、用户隔离和渲染定位有回归测试覆盖。

后续修正验证：12 条独立特效已经在其他素材上重建；与相同素材的未处理帧进行差异检查，排除只有标签变化的情况。5 条缺少独立视频素材的历史知识保留原片入口，效果示例标为待补齐。见 `data/rebuilt-effect-validation.json` 与 `data/rebuilt-effect-examples.jpg`。
