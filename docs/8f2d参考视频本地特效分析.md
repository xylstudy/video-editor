## 节拍与切点

本地检测到的主要节拍包括：`3.077s`、`4.238s`、`5.248s`、`7.012s`、`7.628s`、`8.789s`、`10.681s`、`11.877s`、`14.373s`。参考片的关键变化点 `3.03s`、`4.27s`、`5.23s`、`6.90s`、`7.87s`、`8.87s`、`10.87s`、`12.00s`、`14.53s` 基本落在节拍或强起音附近。

任务 6 虽然保持了总时长，但 Planner 生成的累计切点是 `2.708s`、`5.300s`、`7.088s`、`9.117s`、`9.895s`、`12.130s`、`14.427s`。它只对齐了总时长，没有保留参考片的切点序列，因此节奏骨架已经发生变化。

## 任务 6 没有迁移出来的内容

1. **全片最显眼的音乐播放器 UI 消失了。** 参考片用它连接前四秒的两个场景，并承担 Hook；新成片只用了普通字幕。
2. **4.07–4.34s 的故障遮罩没有迁移。** 当前方案写成了 `fade/cut` 一类通用转场，没有表达彩色噪点块和遮罩揭示。
3. **6.77–6.97s 的竖向切片转场没有迁移。** 当前 `slide` 只是整层移动，视觉结构不同。
4. **短黑场、硬切和节拍位置被泛化。** 方案使用 `dissolve`、`blur_in`、`zoom_flash` 等通用风格，改变了原片干脆、卡点的切换方式。
5. **结尾 CTA 被错误简化。** 参考片是搜索框、平台标识、二维码组成的信息卡；任务 6 生成了米色背景的 typewriter 文字卡。
6. **画幅发生变化。** 3:4 参考片被迁移成 9:16，悬浮 UI 和结尾信息卡即使复刻也会改变比例和位置关系。

## 根因定位

### 1. 镜头拆分漏掉了“渐进式特效转场”

当前场景检测使用相邻帧差和 HSV 直方图差，阈值为 `0.45`。这种方法适合硬切，却容易把持续 6–12 帧的 glitch reveal、切片 wipe 归入同一大镜头。现有分析将 `3.03–5.93s` 合成一个镜头，漏掉猫咪到冰饮的独立转场；又将 `5.93–7.87s` 合成一个镜头，漏掉出口牌到餐桌的切片转场。

### 2. `VideoStructure.shots` 的时间字段被代码写成了零

`agents/analyst.py` 的 `build_video_structure()` 在构造每个 `ShotInfo` 时固定写入：

```python
start_time=0, end_time=0, duration=0
```

真实时间只留在 `raw_shot_analyses`，而 Planner 读取的结构化 `shots` 丢失了时间。因此 Planner 无法按参考视频的原始切点复现节奏，只能重新分配时长。

### 3. 包装分析在结构化时大量丢字段

分析 Prompt 会产出 `title_cards`、`transitions_used`、`stickers_effects`、详细调色等信息，但 `build_video_structure()` 只保留了字幕字体、字幕位置、字幕动画和一个 `color_grade`。音乐 UI、故障遮罩、搜索框 CTA 等包装特征没有进入 Planner 的稳定输入契约。

### 4. Planner 选择了“情绪通用效果”，没有复制“参考片视觉语法”

任务 6 的方案使用了 `hero_push_in`、`cinematic_grain`、`kinetic_warp`、`focus_blur_resolve`。这些效果能增加动态感，但与参考片的 UI 覆盖、故障遮罩、切片 wipe 和信息卡结构不是同一类手法。

### 5. Renderer 超时后的兜底进一步压缩了效果种类

本次 Renderer 模型调用超时后，确定性兜底只映射了推近、颗粒、动感扭曲和模糊恢复，没有根据参考片的包装分析生成跨镜头覆盖层，也没有重写 `transition_in`。Remotion 本身已有 `glitch`、`wipe_*`、`flash_black` 等能力，但方案没有正确选择它们。

## 修正方向

下一轮应先修数据链，而不是继续堆 Planner 文案：

1. 保留每个参考镜头的真实 `start_time/end_time/duration`，并把参考切点作为 Planner 的强约束。
2. 增加独立的 `effect_tracks`，记录可跨镜头持续的效果，至少包含 `start`、`end`、`type`、`persistence`、`parameters`。
3. 对 4–12 帧的渐进式转场使用时间窗口检测，识别 glitch reveal、切片 wipe 和短黑场，不能只看相邻帧是否超过阈值。
4. 将包装字段完整传入 Gene/Planner：悬浮 UI、贴纸、结构化 CTA、调色、特效转场和跨镜头连续性。
5. 新增 `floating_music_ui` 与 `search_cta_card` 组件；竖向切片转场可在现有 `DualTransitions` 上新增 `slice_wipe`。
6. 让 Planner 明确区分“必须迁移的标志性手法”和“可按素材替换的普通镜头内容”。

本片最需要迁移的三个识别点是：**跨镜头悬浮音乐 UI、彩色故障遮罩揭示、搜索框式 CTA 结尾卡**。如果这三个没有实现，即使镜头内容和总时长相似，观感仍会像另一套模板。
