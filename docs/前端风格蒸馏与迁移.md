# 前端风格蒸馏与迁移

日期：2026-10-20。参考站点：`http://10.20.185.16:5180/?document=team-demo&view=canvas`。

这次提炼的是参考站的布局、配色、组件层级和工作室交互方式，并适配到 Video Claw 现有的视频创作流程。参考依据包括站点的 App、Sidebar、Dashboard、CanvasEditor 组件结构和样式表。

## 设计规则

| 元素 | 迁移规则 |
| --- | --- |
| 页面结构 | 深紫侧栏、浅灰紫工作区、固定顶部上下文栏 |
| 主色 | 紫色 `#7154df`；浅紫选中背景 `#eee9ff` |

| 编辑区 | 镜头列表 → 素材预览 → 属性编辑；窄屏按顺序堆叠 |

## 已迁移的界面

- `Layout.jsx`：带说明的导航、页面上下文、助手快捷入口、用户区和真实后端连接状态。健康状态来自 `/api/health`，每 30 秒检查一次，不代表每个模型或任务都处于运行中。
- `Dashboard.jsx`：品牌主视觉、真实统计数据、最近任务和三步创作流程。
- `AuthShell.jsx`、登录和注册页：统一的品牌区与表单区。
- `ProjectDetail.jsx`：参考视频与素材切换预览、素材卡片、生成条件和任务侧栏。
- `StoryboardEditor.jsx`：三栏分镜工作室；保留草案版本、顺序调整、素材选择、字幕、时长、转场、保存与确认渲染流程。
- `Works.jsx`：浅色卡片承载参考视频和生成成片的双栏对照。
- `ui.jsx`、`index.css`：统一按钮、卡片、状态、表单、响应式布局和减少动画偏好。

分镜工作室当前预览的是原始素材，最终的字幕、转场和动效仍在确认后的渲染阶段生成。界面已明确说明这一点。

## 基因库与知识库的信息层级

基因列表改为关键帧卡片，显示时长、镜头数、平均镜头时长、结构与情绪，支持名称搜索和状态筛选。纯哈希名称在列表中显示为结构类型与基因编号，原始名称保留在详情中。

知识列表只展示短摘要和适用场景。结构模板、节奏模式和情绪设计使用条目已有的结构化数据绘制概览；其他技法使用分类图标，不把图标当作效果演示。点开侧边详情后可读完整说明、查看来源视频和按需播放真实演示视频。正文搜索仍覆盖完整内容。

基因报告分为核心概览、开场 Hook、结构与节奏、包装风格和镜头标注。关键技法以可展开条目呈现，长说明提供全文展开入口。

验证结果见 `data/library-ui-checks.json`，截图为 `data/library-*.png`。检查包括列表密度、搜索、筛选、详情完整性、弹窗关闭、来源跳转及移动布局。对比浏览前后的接口响应，基因与个人知识数据没有变化。

## 作品集与统计洞察的统一

作品集采用与基因库相同的封面网格、短标题和底部操作栏。封面在进入可视范围后从生成视频截取一帧，随后释放解码器；列表不保留视频播放器，也不会自动播放。完整的参考片与生成片对照放在宽详情抽屉中，任务、项目和下载入口保留。新增名称／任务／参考视频搜索和生成模式筛选。

洞察的视频特征库采用同一套封面卡片。综合统计与单视频报告使用浅色柱形摘要、关键数值和样本量；点开后查看完整结论与分布。镜头时间线、情绪流和原始判断依据按需展开。单视频缺少独立统计时明确显示缺失状态，避免将综合计数误当作该视频的结果。

复用 `LibraryDetail.jsx` 承载知识、作品和洞察详情；封面由 `MediaCover.jsx` 按需加载，统计摘要使用 `InsightGraphic.jsx`。本轮未修改后端数据或调用分析模型。

验证结果为 `data/gallery-insights-checks.json`，截图为 `data/gallery-insights-*.png`。覆盖封面生成、搜索筛选、正确的参考片与成片地址、详情／下载／项目入口、综合与独立报告的统计范围、镜头依据、移动布局，以及模拟的缺失报告、空数据、失败和恢复状态。知识库共享详情组件也完成了回归检查。
