# 执行用量与费用统计

任务详情页的“本次执行用量”集中展示 Token、模型费用估算、工具调用和模型请求次数。展开后可以查看各阶段、各模型及具体工具的明细。执行期间持续更新，分镜确认前后的记录累积在同一个任务中，任务后的知识与示例沉淀也计入。

## 统计口径

- Token 使用模型接口实际返回的输入、输出、总量和缓存命中量。不依据提示词长度猜测；没有返回的用量保持未知，部分缺失时明确提示。
- 模型请求按实际 HTTP 尝试计数。重试、被截断后重新请求等都会计入；已返回 Token 的失败尝试同样计入消耗。模拟响应单独标记。
- 工具覆盖已注册的 Agent 工具及视频、音频、人脸、渲染和知识示例工具。嵌套封装只记录最底层实际操作，避免同一次抽帧既算 Agent 适配器又算视频工具。普通 Python 函数调用、数据库查询、前端轮询不计入。
- 复用已有分析报告不会把先前任务的模型费用重新记到当前任务。

## 单价与费用

在“模型与 API”中编辑模型，可设置每百万 Token 的输入价、输出价、可选缓存输入价，以及人民币或美元币种。输入价和输出价需要同时填写或同时留空；明确填写 0 才表示配置为免费。

费用计算方式：

```text
估算费用 = [(输入 Token - 缓存命中 Token) × 输入单价
          + 缓存命中 Token × 缓存输入单价
          + 输出 Token × 输出单价] / 1,000,000
```

每次请求保存当时使用的单价快照，之后编辑模型价格不回算历史。不同币种分别展示，不自动换汇；只配置部分模型时标记为部分计价，未知项不会显示成零元。

未手工设置价格时，官方 `api.deepseek.com` 的 Flash、V4 Pro 及明确兼容的 Flash 旧名称使用 **2026-10-26 核对的官方峰时参考价**，页面标为参考上限；不将该价格套用到同名第三方网关。来源：[DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。低峰、优惠和账户折扣可能降低实际费用。

缓存明细未返回时按普通输入价估算。统计不包含本机渲染、电费、第三方图片生成等其他服务费用，最终以服务商账单为准。

## 保存与隔离

记录保存在该用户任务目录的 `metrics/events/` 和 `metrics/sessions/` 中，采用独立文件和原子替换，跨进程共用任务目录。上下文通过任务范围和子进程环境传递，不修改全局用户配置。事件记录不保存提示词、模型正文或 API Key。

接口为 `GET /api/tasks/{task_id}/usage`，使用与任务详情一致的用户归属校验。旧版 SQLite 自动补充模型价格字段，保留原有配置。

历史任务没有完整事件时，仅展示已有评测中的 Token 汇总，并注明可能不完整；费用和工具次数不能准确追溯，保持未计价或未提供，不伪造回填。

## 代码入口

- `viral-structure-engine/config/usage_tracking.py`：任务上下文、模型请求和工具事件采集。
- `web/backend/task_usage.py`：任务级汇总、缓存费用计算和历史数据兼容。
- `web/frontend/src/components/TaskUsage.jsx`：任务详情展示和执行期间刷新。
- `web/frontend/src/pages/Settings.jsx`：模型单价设置。
