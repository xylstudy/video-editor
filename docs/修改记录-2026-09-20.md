# 修改记录｜2026-09-20

## 本次目标

完善多智能体视频生成系统的工具协议、运行评测和成片评测闭环，使 Web 与命令行端到端流程均能保存可追溯的评测结果。

## 完成内容

### 1. Agent 工具协议与能力边界

- 为 Analyst、Planner、Renderer、Reviewer 等专职 Agent 的工具补充统一的 `name`、`description`、`inputSchema` 元数据。
- 通过共享注册逻辑校验工具声明，并维持按 Agent 隔离的工具集，避免无关 Agent 获得不属于自己的执行能力。

### 2. 分镜方案与运行过程评测

- 保留 10 维 Reviewer，对参考结构保真和素材适配/剪辑质量分别给分并输出结构化建议。
- 新增运行记录与离线评测：检查阶段覆盖、失败记录、结构化产物、素材覆盖率、模型请求/重试/mock 响应、Token 用量及方案版本指纹。
- 草案生成后产出 `awaiting_confirmation`/`ready_for_render` 报告；确认分镜后重新评审确认稿，避免复用旧版本评审结果。

### 3. 成片评测

- 新增 `evaluation/video_review.py`：对最终 MP4 完成全片解码、时长、音轨/静音、疑似黑屏和长静帧检查。
- 按确认分镜的时间轴抽取头、中、尾代表帧；配置视觉模型时，以这些帧、确认分镜和参考结构为证据，评估 Hook 呈现、分镜兑现、素材适配、转场节奏、画面连续性、字幕可读性和包装一致性。
- 分镜评审和成片评审分别保存为 `reviewer/review_result.json` 与 `render_reviewer/render_review.json`。成片主观分数暂仅用于诊断，待人工标注基准集校准阈值后再作为自动通过条件。

### 4. Web 集成

- 确认并渲染分镜后自动生成最终评测；渲染或评审失败也会保留失败报告和已有视频。
- 任务详情页展示方案 Reviewer 分、成片视觉评审分、全片解码、音轨、素材覆盖和问题时间点。

## 验证
